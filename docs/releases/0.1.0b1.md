Initial beta of Heating Pulse Controller v2 for Home Assistant 2026.9 or later. Tested against HA Core 2026.9.3 / Python 3.14.

- Adaptive radiator pulses with a fixed calibrated Sonoff valve opening, per-cycle plateau detection, three-hour reference expiry, residual-warming compensation and temperature-based cooling readiness.
- Home Assistant configuration/options UI, nine diagnostic sensors, control switch, reset buttons and versioned calibration storage.
- Legacy-controller guards, serialised actuator commands, fresh-data checks, timeouts and shutdown/unload handling.
- 51 local tests passed; Linux CI runs against the same pinned HA version.

### Install

Add `https://github.com/blackeyeliner/heating-pulse-controller-v2` to HACS Custom repositories as an Integration. Enable prerelease versions to select `v0.1.0b1`, download, restart HA and add Heating Pulse Controller v2 in Devices & services.

The attached ZIP is an alternative for manual installation: extract its `custom_components/heating_pulse_controller_v2/` directory into HA's `/config/custom_components/`. HACS installs directly from the repository. A SHA-256 file accompanies the ZIP.

### Limitations

Control starts disabled after every HA restart or integration reload. Configuring the integration sends no valve commands. Initial tuning and unchanged-sensor reporting must be verified before enabling control. Hardware commissioning has not been completed; surface temperature alone does not establish water savings. Software closure cannot be guaranteed during a HA, network or power outage.

See README.md and docs/validation.md for setup, behaviour and validation limits.
