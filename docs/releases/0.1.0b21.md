# Beta21: red Antifreeze display while keeping the thermostat visually Off

Autonomous frost heating now shows Antifreeze with red temperature, status text and dial arc in the bundled thermostat card. Room title, menu and buttons retain their ordinary colours. Ordinary heating remains standard orange Heating; idle/off colours remain unchanged. The native dial is presented as inactive Off during frost operation, so autonomous protection no longer makes it appear that ordinary thermostat heating was enabled. The Heat control remains available to resume ordinary heating with the remembered target.

Presentation is scoped to the card. Backend mode remains Off and backend hvac_action accurately remains heating for firmware protection; no mode, target or valve command is sent by presentation. The native label template is restored outside frost heating. Tests cover red styling, immutable source state, Off presentation, restoration and existing card lifecycle. UI-only browser checks against the installed HA frontend confirm red Antifreeze/inactive Off, grey Off and orange Heating.

The legacy logical 0/5 valve graph is retained. The draft percentage-display change was not released. No heating algorithm, valve-setting or budget change.
