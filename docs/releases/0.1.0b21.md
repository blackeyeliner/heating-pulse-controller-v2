# Beta21: red Antifreeze display while keeping the thermostat visually Off

Autonomous frost heating now shows Antifreeze in red throughout the bundled thermostat card. Ordinary heating remains standard orange Heating; idle/off colours remain unchanged. The native dial is presented as inactive Off during frost operation, so autonomous protection no longer makes it appear that ordinary thermostat heating was enabled. The Heat control remains available to resume ordinary heating with the remembered target.

Presentation is scoped to the card. Backend mode remains Off and backend hvac_action accurately remains heating for firmware protection; no mode, target or valve command is sent by presentation. The native label template is restored outside frost heating. Tests cover red styling, immutable source state, Off presentation, restoration and existing card lifecycle. UI-only browser checks against the installed HA frontend confirm red Antifreeze/inactive Off, grey Off and orange Heating.

The owner chose to retain the legacy logical0/5 valve graph. The draft percentage-display change and unreleased beta20 tag were cancelled and never installed. The office24 °C frost test completed and protection was restored to10 °C. No heating algorithm, angle or budget change.
