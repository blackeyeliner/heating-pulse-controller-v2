# Beta19: show firmware frost activity in valve graphs and thermostat colour

After firmware Off handoff, the logical valve graph now uses TRV-reported activity: idle is0, heating is5 (the existing logical pulse marker), missing activity stays unknown. The thermostat turns heating orange when firmware reports frost heating while retaining Off mode and the actual frost setpoint.

The logical valve sensor additionally exposes `estimated_opening_percent`, calculated from the configured opening limit during reported heating and100 minus the closing limit during reported idle. `position_measured: false` explicitly distinguishes this end-position estimate from measured mechanical stem position. TRV/limit changes update telemetry without waiting for temperature reports. No control commands, setpoints, frost handoff, pulse detection or budget policy changed.
