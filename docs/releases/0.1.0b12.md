Beta 12 adds optional mobile emergency notification and backup inverter heating for loss of reliable radiator-valve control.

- Select a notify service and a list of backup climates in Configure. Only critical actuator faults trigger the actions; data/calibration recovery PWM remains unchanged.
- Request heat / 20 °C on every selected climate. Isolate failed heads and retry failed notification/backup requests once per minute. Remember acknowledged actions and active incidents across reload/restart. Never automatically stop the reserve; manual intervention is required.
- Require non-optimistic changed-limit readback within 15 seconds. An accepted MQTT service call without the requested limit feedback is a control failure. Already-matching states are accepted without requiring an identical report, so detection is not a continuous communication heartbeat. No claim of physical stem/flow confirmation.
- Expose scalar emergency/backup status in Phase attributes. Passive initial setup; existing active emergencies resume pending actions on restart without enabling normal radiator control.

Tests cover deduplication, real Store reload, notification/partial climate failure and retries, independent sensor recovery, unavailable valve, missing open/close feedback, configuration validation and manual backup preservation. Production commissioning does not deliberately interrupt valve communications or activate the apartment reserve.
