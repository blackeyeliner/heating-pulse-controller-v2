Fix where Home Assistant displays the controller configuration.

Previous betas declared `integration_type: helper`, placing configured rooms in the Helpers tab and excluding them from the Integrations overview. Declare the controller as a service integration so it appears under Settings → Devices & services → Integrations.

Update through HACS and restart Home Assistant to refresh integration metadata. Existing config entries, entity IDs, settings and calibration storage are retained. Do not remove or recreate the configured room. Control starts disabled after restart, as before.

This release changes metadata and documentation only; the runtime and heating algorithm are unchanged from beta 2. Beta 2 can still be configured through the Helpers tab if postponing the update.
