# Beta20: replace the legacy five-percent marker with calculated opening

The existing valve-position graph now displays the configured end-position estimate selected by firmware running state: opening limit when heating,100 minus the closing limit when idle. This replaces the misleading fixed5 heating marker, including autonomous frost heating (Office21 instead of5). Sensor attributes identify the source and explicitly mark position_measured false: these are device settings plus running state, not mechanical stem telemetry or water flow.

Missing/invalid feedback, reconnects and critical faults remain unknown. No valve limits, protection thresholds or control algorithm change. Tests cover autonomous frost heating and ordinary configured opening/closing estimates.
