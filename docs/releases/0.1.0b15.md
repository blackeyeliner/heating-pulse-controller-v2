# Beta15: reliable thermostat-card startup

Fixes intermittent "Custom element does not exist: heating-pulse-thermostat-card" on a fresh page after HA restart. Extra JavaScript modules can run before HA installs its scoped custom-element registry; early registration reaches the original registry and is then invisible to Lovelace.

The bundled module now waits for home-assistant to be defined before resolving HTMLElement and registering its card. A regression test simulates HA replacing both the registry and element base class during bootstrap. No control algorithm, persisted state, room tuning or entity IDs change. Refresh the HA page after updating.
