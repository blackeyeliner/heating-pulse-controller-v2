# Beta22: Antifreeze uses the standard Heating colour scope

During autonomous frost heating, only the filled dial arc up to the frost target, Antifreeze status and current room temperature are red. The large target digits, inactive track, title, menu and buttons keep their normal colours. Ordinary Heating remains orange.

The native temperature control uses Heating styling only during its synchronous render call. Its reactive state, the mode selector and the actual climate entity remain Off. Presentation sends no services and restores the native rendering outside frost activity. This replaces beta21’s inactive-circle and overly broad temperature styling.

Verified in the installed HA frontend with UI-only state clones, including red status/current temperature, white target, active arc and Off mode selection. Frontend regression tests cover state preservation and restoration. No heating algorithm, valve setting or logical0/5 graph change. Frost protection remains10 °C in all rooms.
